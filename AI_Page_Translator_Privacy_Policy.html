Privacy Policy for AI Page Translator

Last Updated: October 29, 2026

AI Page Translator ("we", "our", or "the Extension") is a Chrome browser extension that uses the Google Gemini API to translate web pages into the language selected by the user.

This Privacy Policy explains what information the Extension handles, how it is used, and how it is protected.

1. Information We Handle

Website Content

When the user chooses to translate a web page, the Extension processes text content from the current web page.

The relevant text may be sent to the Google Gemini API in order to generate the requested translation. This processing is necessary for the core functionality of the Extension.

The Extension does not use website content for advertising, profiling, or unrelated purposes.

Gemini API Key

The Extension allows users to provide their own Google Gemini API key.

The API key is stored locally in the user's browser using Chrome's storage functionality. The developer of AI Page Translator does not receive or have access to the user's API key.

The API key is used to authenticate requests to the Google Gemini API.

Other Information

The Extension may store user-selected settings, such as the preferred translation language and selected AI model, locally in the user's browser.

The Extension does not intentionally collect:

  • Names or other personally identifiable information
  • Financial or payment information
  • Health or medical information
  • Precise location information
  • Personal communications
  • Browsing history
  • Advertising profiles
  • User activity unrelated to the translation functionality

2. How Information Is Used

Information handled by the Extension is used only to provide its core functionality, including:

  • Translating text displayed on web pages
  • Sending translation requests to the Google Gemini API
  • Remembering user preferences and settings
  • Authenticating API requests using the user's own Gemini API key

We do not sell user data. We do not use user data for targeted advertising or unrelated purposes.

3. Third-Party Services

AI Page Translator uses the Google Gemini API to process translation requests.

When a user requests a translation, relevant webpage text may be transmitted to Google through the Gemini API.

The handling of information by Google is subject to Google's applicable terms and privacy policies.

The Extension does not operate its own server for collecting or storing users' webpage content or Gemini API keys.

4. Data Storage

The Extension uses Chrome's local storage functionality to store information such as:

  • The user's Gemini API key
  • Selected translation language
  • Selected AI model
  • Other necessary local settings

This information is stored locally in the user's browser. The developer does not maintain a database containing users' API keys or webpage content.

5. Data Sharing

We do not sell, rent, or trade user data.

Website text may be transmitted to Google Gemini because this transfer is necessary to provide the translation functionality requested by the user.

We do not share user information with advertisers, data brokers, or other unrelated third parties.

6. Data Security

We take reasonable measures to limit access to information handled by the Extension.

Because the Gemini API key is stored locally in the user's browser, users should protect access to their Chrome profile and API credentials.

Users are responsible for using and managing their own Gemini API key in accordance with Google's applicable policies and terms.

7. User Control

Users can:

  • Remove their Gemini API key from the Extension
  • Change their translation language
  • Change their selected AI model
  • Stop using the Extension at any time
  • Remove the Extension from Chrome

8. Children's Privacy

AI Page Translator is not specifically directed toward children under the age of 13. We do not intentionally collect personal information from children.

9. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect changes to the Extension or applicable requirements. Any updated version will include a revised "Last Updated" date.
